Private single-user application

Sylfrena

Sylfrena Private Runtime is a personal operating assistant built exclusively for Weston Deering. It supports private conversation continuity, careful planning, and explicitly authorized creation of private Google Drive outputs.

How Google Drive access is used

Sylfrena requests the narrow drive.file permission. This allows the application to create and manage only the Google Drive files it creates or files the user explicitly authorizes for the application. It does not request unrestricted access to the user's entire Drive.

Google Drive access is used only to produce private, user-requested documents and preserve bounded personal-assistant outputs. Sylfrena does not independently publish, share, sell, or advertise with Google user data.

Private by design

This application is not a public product and is not offered to unknown users. Consequential external actions require explicit authorization, and Google access can be revoked by the account owner at any time.
