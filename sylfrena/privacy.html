Privacy Policy

Effective date: September 2, 2026

Sylfrena Private Runtime is a private, single-user personal assistant operated for Weston Deering. This policy explains how it accesses and uses Google user data.

Google data accessed

Sylfrena uses the Google Drive drive.file scope. That permission is limited to files the application creates and files the account owner explicitly authorizes for the application. Sylfrena does not request unrestricted access to all files in Google Drive.

How data is used

Google Drive access is used to create and manage private assistant outputs requested or expressly authorized by the account owner, confirm successful file creation, and prevent accidental duplicate outputs. Google user data is used only to provide these user-facing functions.

Storage and security

OAuth credentials are maintained as protected runtime secrets and are not placed in public source code. Sylfrena retains only the operational records needed for continuity, authorization receipts, reliability, and duplicate prevention. Access is bounded to the private runtime and the account owner.

Service providers

Information may be processed by infrastructure and AI service providers only as necessary to operate the private assistant and fulfill the account owner's requests. Google user data is not sold, rented, used for advertising, or shared for unrelated purposes.

Retention and deletion

The account owner controls files created in Google Drive and may delete them at any time. The owner may revoke the application's Google access through Google Account security settings. Operational records may be deleted when no longer needed for the private runtime.

Google API Services User Data Policy

Sylfrena's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Contact

Questions may be directed to the user-support address displayed on Sylfrena's Google OAuth consent screen.
